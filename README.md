# ShareGNSS documentation site

Public overview, privacy policy and setup/support guide for ShareGNSS.

- Website: https://fa1keh-soft.github.io/sharegnss-site/
- Privacy: https://fa1keh-soft.github.io/sharegnss-site/privacy.html
- Support: https://fa1keh-soft.github.io/sharegnss-site/support.html
- Contact: fa1keh.soft@gmail.com

Publish the `main` branch root through GitHub Pages with HTTPS enabled. The site is plain HTML and CSS; it needs no build step, packages, JavaScript or third-party embeds. `.nojekyll` preserves the static files.

This repository contains website files and approved public artwork only. The Android application source, release signing material, raw phone captures, purchase data and internal release records are not part of it.

The privacy text was checked against ShareGNSS 0.3.4 (9) and includes local GNSS processing, selected paired-device sharing, preferences, trial timing, signed purchase evidence, support email and GitHub Pages hosting. Update the policy date and app disclosures when data handling changes.

Images use the approved icon and redacted outdoor phone/Windows/N.I.N.A. captures. The guide screenshots show controls rather than a completed live import. Keep the privacy redactions intact in any replacements.

ShareGNSS is independent of the N.I.N.A. project. No open-source license for the Android app is granted by publishing these documentation files.
